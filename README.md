# MoneyTMS — Think bigger.

Desktop design preview built with React, Vite, Tailwind CSS, and Framer Motion.

## Open
Double-click `Open MoneyTMS.command`, or run `npm run dev` from this folder. Use `npm run build` for a production build and `npm run preview` to inspect it.

## Design
Cinematic full-viewport architecture, oversized Inter Tight typography, restrained MoneyTMS blue and green, parallax imagery, entrance reveals, and generous editorial sections. Pipe and OGON.ES informed the visual scale and restraint, not the business content or functionality. The custom wordmark is an exploratory design treatment; the original logo remains in public/logo.jpg.

## Qualification flow
Monthly business revenue → funding requested → business/contact details → review → demo completion. Required selections, email/phone validation, contact-request acknowledgment, previous-step navigation, and a native accessible modal are implemented. Selection and form data live only in memory. Refreshing clears them.

This is a design preview. No information is sent or persisted, and no real approval or funding decision is made. A production backend/CRM, delivery confirmation, server validation, abuse protection, and reviewed live disclosures remain to be connected after design approval.
